# Accessibility (Backbase Angular)

## Minimum

- [ ] Labeled form controls
- [ ] Keyboard access for custom interactive widgets
- [ ] Visible focus
- [ ] Accessible names on icon buttons
- [ ] Don’t rely on color alone for errors
- [ ] Prefer DS components that already implement a11y behaviors

## Practice

- Fix `@angular-eslint` / axe findings — don’t disable rules
- Dialogs/drawers: use the estate’s modal primitives (focus trap)
- Announce async errors when sibling journeys do (live regions)
