# React — Version Compatibility

| Topic | Rule |
|---|---|
| React 17 vs 18+ | New JSX transform / hooks — match installed |
| React 19 APIs | Only if lockfile has React 19 |
| Next App Router | Server Components default — don’t client-ify everything |
| Next Pages | Don’t move a page to `app/` in a feature PR |
| Concurrent features | Use patterns already in codebase |
