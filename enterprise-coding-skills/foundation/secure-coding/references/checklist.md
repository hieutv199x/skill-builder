# Secure Coding Checklist

- [ ] Authn/authz enforced server-side
- [ ] Inputs validated at trust boundaries
- [ ] No injection (SQL/command/template/LDAP)
- [ ] No secrets in source/tests/logs/client bundles
- [ ] Sensitive data minimized in errors/logs
- [ ] Safe CORS/cookie defaults where applicable
- [ ] New dependencies justified
- [ ] Path operations reject traversal
